`generated-phase-control` definition before opening Designer. Generate packages
the winning module and definition; do not load this preset from the generated
canvas. The hashed phase-control definition authorizes Copilot Autopilot;
the adapter's browser capability declaration does not grant server-side
managed-run access. The generated host validates phase progress and keeps
execution safeguards.
